## 封面的可测量参数（2026-09-20 从像素里量出来的）

- 画布 1280×640，RGB、无 PNG 文本元数据。
- npx 徽章：左边框 `x=96`、上 `y=470`、下 `y=515`、右 `x=371`（旧名时），圆角半径 **8**（边框 1px，纯色）；
  填充 `(15,20,28)`、边框 `(30,38,48)`；徽章周围背景在那一带是纯色 `(11,14,19)`。
- 徽章内的等宽文字：**字距正好 10px**、第一个字格从 `x=109` 起、基线行 `y=499`、色 ≈ `(142,145,148)`。
- 字体指纹：按列统计 ink → 取**字符簇起点**，等宽字的簇起点差就是字距。10px 落在 Consolas 的
  `0.5498 em` 上 ⇒ 约 **18.19px**（这台机器的字库里只有 Consolas / Lucida Console / Courier New 三个等宽字体，
  后两个带衬线、形状对不上；粗体质量比原图重 38%，也排除）。
- 右侧「· 开源 · MIT」那一段的等宽字距无关，它跟着徽章右移即可。

## 改名或改版时怎么改

**截图：重新截，不要 P。** 截图里容易出现真实记录（账号名、二维码、个人图片文件名），既然要重截，就顺手换成示例数据。
截图窗口宽 ≥ 1200px，否则三栏会塌成一栏。

**封面：** 这台机器上没有 ImageMagick / Python，Chrome 在沙箱里画不出内容（`--headless=old` 出的是空图），
可用的是下面这套，走的是"只改徽章那一小块、其余像素一个不动"的路子：

1. Node 自带 `zlib` + 手写 PNG 解/编码（IHDR/IDAT、5 种 filter 行过滤）就能读写像素，不需要任何依赖；
2. PowerShell + `System.Drawing`（GDI+，`TextRenderingHint.ClearTypeGridFit`）**能渲染带子像素彩边的等宽文字**，
   和原图是同一种渲染风格；背景用徽章填充色渲染，整块拷进去就是无缝合成；
3. 徽章加长：文字每多一个字符就多 10px ⇒ 右边缘和右边那一段文字整体右移同样的像素数；
   那一带背景是纯色，整块搬运看不出接缝；被覆盖的区域先按纯色重画（填充 / 边框 / 背景三种色）。

**不要动 emoji 图标**：封面用的是**彩色 emoji**（🔗🖼🔑☁️💬 那一类），GDI+ 只能渲染单色版本，重画会一眼看出不同。
只有等宽文字、纯色矩形与 1px 边框能这样修。
